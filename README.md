# Fatherson Recovery

Next.js (App Router) site.

## Stack
- Next.js 16 (App Router, TypeScript)
- Tailwind CSS v4
- Biome (lint + format)
- pnpm (Node 22 LTS)

## Develop
```bash
pnpm install
pnpm dev
```
App at http://localhost:3000.

## Scripts
- `pnpm dev` — dev server
- `pnpm build` — production build
- `pnpm lint` — Biome check
- `pnpm format` — Biome format
